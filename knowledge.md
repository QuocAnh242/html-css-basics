# Session 1 - Introductions

- same root ./

- leveled root ../

- Name convention should be general and easy to understand

- Attribute _attribute_ example: 'sample', 'hello-world-1', 'hello-world-2',..

- Tag _tag_ example: <div></div>, <span> </span>,..

- CSS runs on top down, if 2 css duplicates will run on the top code first

- Div _div_ is a block contains other attribute

- Image _img_ is an inline tag, auto-closed, use to display images with 2 attributes 'src' & 'alt'

- Span _span_ is an inline tag, used for short texts

- Headings: h1, h2, h3,... h6

- hyperlink a _a_ is an inline tag, for link to other website/href with 2 attributes 'href' & 'target', 'rel'
