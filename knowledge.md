# Session 1 - Introductions

- same root ./

- leveled root ../

- Name convention should be general and easy to understand

- Attribute _attribute_ example: 'sample', 'hello-world-1', 'hello-world-2',..

- Tag _tag_ example: <div></div>, <span> </span>,..

- CSS runs on top down, if 2 css duplicates will run on the top code first

- Div _div_ is a block contains other attribute

- Image _img_ is an inline tag, auto-closed, use to display images with 2 attributes 'src' & 'alt'

- Span _span_ is an inline tag, used for short texts

- Headings: h1, h2, h3,... h6

- hyperlink a _a_ is an inline tag, for link to other website/href with 2 attributes 'href' & 'target', 'rel'

# Session 2 - Font setups, CSS resets & selectors

- Using link or import for Google Fonts

- Font-weight: the bold and weight of the letter, 100 -> 900, (normal, bold, bolder, extra bold, light, thin, regular, medium, semibold,..)

- Font-family: establish font and name

- Serif: Letter with small extra lines

- Sans-serif: Letter font without 'feet'

- CSS Selectors: tag, class, id, attribute

- Tags: h1, h2, h3, div, body, span, a

- Class: .name, .tour, .tour-header

- Id: #header, #content

- Attribute: 'sample', 'hello-world-1', 'hello-world-2',..

- CSS Structures

- User agent stylesheet: Default CSS of broswers

- CSS Reset: Used to reset CSS default of broswers

- Special Selector: '\ \* > ~ +'

# Session 3 - Box-sizing, Padding, Margin, Border, Width, Height, Px unit

- Box-sizing: margin, padding, border, width, height, px unit

- color / background-color: red, hex(#ffa400), rgb(1,2,4), rgba(1,0,984,0,1)

- Alpha (opacity): 0 --> 1

- Box-sizing: content-box, border-box

* Content-box: width + padding + border
* Border-box: Include padding & border

- width, height: Manage width & height

- Padding: (4) top right left bottom, (3) top right-left bottom, (2) top-bottom right-left, (1) all

- border (border-width, border-style, border-color)

* border-style: solid - dashed - dotted - double
* shorthand example: 5px solid black

- sizing unit: px, em, rem, vw, vh, %

# Session 4 - Margin, Display & Inline-height

# Session 5 - Min-width, Max-witdth, Basic Flexbox

- Min-width: the minimum of width required >=

- Max-width: the maximum of width required <=

- Flexbox, flex direction

- Align-items: stretch, flex-start, flex-end, center, baseline (Text baseline)

- Justify-content: center, space-around, flex-end, flex-start

- Flex-wrap: sets whether flex items are forced onto one line or can wrap onto multiple lines. If wrapping is allowed, it sets the direction that lines are stacked. (wrap, no-wrap, wrap-reverse, wrap balance)

- Gap: column-gap/row-gap, margin top-bottom

- calc : function to calculate

- Component: Reuse code as a component
